1. 시험 설계

동작내용명령 (2회)
① 자동 배정 이동닿는 팔 중 가까운 팔이 자동으로 수행빨간 블록을 왼쪽 뒤 구석으로 옮겨
초록 블록을 오른쪽 앞으로 옮겨
② 팔 지정 이동"왼팔로/오른팔로" 지정한 팔이 수행왼팔로 노란 블록을 왼쪽으로 옮겨
오른팔로 파란 블록을 오른쪽 뒤 구석으로 옮겨
③ 쌓기블록을 다른 블록 위에 올림빨간 블록을 노란 블록 위에 쌓아
파란 블록을 초록 블록 위에 쌓아
④ 팔 간 전달한 팔로 안 되는 이동을 공유 지점을 거쳐 2단계로빨간 블록을 오른쪽으로 옮겨
파란 블록을 왼쪽으로 옮겨
⑤ 양팔 협동 운반그릇(트레이) 양끝 손잡이를 두 팔이 함께 들어 옮김그릇을 두 팔로 들어서 뒤로 옮겨
쟁반을 양손으로 들어서 가운데로 옮겨

매 회차 시작 전에 블록·트레이를 초기 위치로 되돌림(④는 트레이를 작업 영역 밖으로, ⑤-2는 트레이를 뒤쪽 x = 0.10에서 시작). 판정: 플래너 결과(손목 카메라 집기 확인 + 탑뷰 카메라로 목표 30 mm 이내 확인)와 Gazebo 실제 위치. 쌓기는 위 블록 높이 0.0375 m로 확인.
