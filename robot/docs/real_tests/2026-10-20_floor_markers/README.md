## 마커
- 인쇄 3 cm는 흰 종이 포함. 검은 사각형은 확대 이미지에서 약 72 % → **약 2.2 cm** (가정, 자로 확인 필요).

  이미지에서 검은 사각형 크기로 잰 중심 간격 19.7 × 7.5 cm와 맞는다.
- 호모그래피 잔차: 평균 0.6 mm, 최대 1.4 mm (16 꼭짓점).
- 검출 설정: 마커가 약 36 px로 작고 반사가 있어 기본값에서 46·47이 빠졌다 → `errorCorrectionRate 1.0`, `perspectiveRemovePixelPerCell 8`.
