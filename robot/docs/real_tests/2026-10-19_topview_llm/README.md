# 실물 탑뷰 + LLM 대상 선택 시험 (2026-10-19)

실제 작업 공간 탑뷰 카메라(HFSD SNAP U2, 1920x1080) 한 장으로 비전 → 언어(LLM) → 좌표까지 확인했다.
로봇팔은 움직이지 않았다.

## 파일
| 파일 | 내용 |
|---|---|
| `topview_scene.py` | 탑뷰 캡처 + 색 영역(HSV) 검출 + ArUco(4x4_50) 검출. `python3 topview_scene.py out.jpg` → `out_raw.jpg`, `out.jpg` |
| `pick_target.py` | 비전 후보(색·모양) → Ollama `gemma4:e2b`가 JSON 스키마(enum)로 후보 id 하나 선택 → 픽셀 좌표 출력. `python3 pick_target.py "<명령>" out.jpg [입력 이미지]` (입력 이미지가 없으면 카메라로 찍음) |
| `images/topview5_raw.jpg` | 원본 탑뷰 |
| `images/topview5.jpg` | 원본 검출 결과(색 박스·마커 id) |
| `images/topview5_dark.jpg` | 밝기 60% (`cv2.convertScaleAbs(alpha=0.6)`) — 평균 V 138.7 → 83.2 |
| `images/dark_pick_blue.jpg`, `dark_pick_orange.jpg` | 어두운 이미지에서 LLM이 고른 대상 표시 |
| `run_blue.log`, `run_orange.log` | 아래 결과의 실행 로그 |

다시 돌리기 (`/usr/bin/python3`, Ollama 실행 중):
```bash
python3 pick_target.py "파란색 원형 용기" images/dark_pick_blue.jpg images/topview5_dark.jpg
python3 pick_target.py "주황색 원형 용기" images/dark_pick_orange.jpg images/topview5_dark.jpg
```

## 장면
- 왼쪽 트레이: 의료 소모품 팩, 가운데 트레이: 비어 있음(검은 바닥), 오른쪽 프레임: 파랑·주황 원형 용기.
- ArUco 4x4_50: id 10 ×4(벽 2, 트레이 모서리 2 — 중복이라 기준 불가), 오른쪽 프레임 안 id 7·14·15·16.

## x, y, z 추정 (임시, 오른팔 기준 프레임)
`pixel_to_arm_estimate.py` — 기준점 1개(파랑 뚜껑 픽셀 (1324,685) ↔ 팔 (0.237, −0.011, −0.052))와 가정(카메라 축 = 팔 축, 오른팔 joint1 축 픽셀 행 1010 추정 → 0.73 mm/px, 뚜껑 높이 같음)으로 계산. 로그 `run_xyz_estimate.log`.

| 대상 | x | y | z | 도달 거리 | joint1 행 960~1060일 때 x / y |
|---|---|---|---|---|---|
| blue_round_0 (1347,601) | +0.299 | −0.027 | −0.052 | 0.300 | 0.290~0.310 / −0.025~−0.031 |
| orange_round_0 (1447,631) | +0.277 | −0.101 | −0.052 | 0.294 | 0.271~0.284 / −0.089~−0.117 |

- 오차 수 cm 수준이라 **팔 이동에 쓰지 않는다**. 바닥 마커 46–49로 대체.
- 두 용기 모두 측정 최대 도달(0.296 m) 근처, 뚜껑 윗면 z −0.052는 안전 높이 −0.04보다 낮다 → 자동 집기 전에 용기를 팔 쪽으로 당기거나 안전 높이 규칙을 다시 정해야 한다.

## 발견한 것
- **주황 미검출 → 수정:** 조명에 주황 뚜껑 채도가 약 126으로 떨어져 하한 120에 걸렸다. 하한을 S 80으로 내림.
- **밝기를 낮추면 오검출이 줄었다:** 원본에서는 하단 나무판(주황), 좌하단 흰 벽(회색)이 잡혔으나 60% 이미지는 두 용기만 후보. 좌표 차이는 몇 px.
- **LLM 속성 출력이 섞임:** 주황 결과의 `attributes`가 `주황/원형`(한국어)으로 나옴. 선택은 맞지만, 코드에서 속성 검사를 하려면 속성도 enum으로 제한해야 한다.
- **원형/사각 구분은 크기 기준(가정):** 외곽선 특징으로는 안 갈려서 `minAreaRect` 긴 변 ≥ 115 px면 사각.

## 남은 것
- 미터 좌표: 고유 id 바닥 마커(46–49) 부착 후 픽셀 → 팔 좌표 변환. 이전 기준점(파랑 픽셀 (1324,685) ↔ 팔 (0.237, −0.011))은 카메라·팔이 그대로면 유효 — 마커 변환 결과 검증에 쓴다.
- 요청한 물체가 없을 때 비슷한 것을 고르는 문제: 코드에서 속성 일치 확인 후 거부.
- 회색 용기·팩 검출, HSV 캘리브레이션.
