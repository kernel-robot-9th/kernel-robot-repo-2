## 3. 임시 조치 — 운영 전에 되돌릴 것

| 설정 (`emr/.env`) | 지금 | 하는 일 | 되돌리기 |
|---|---|---|---|

## 5. 로봇 쪽 참고 (웹 문제 아님, 팀원 확인 필요)

- 좁은 칸(4인실·1인실·충전·약제실)에 **들어가거나 나오는 짧은 nav 구간**이 Nav2 `FollowPath error_code 104`로 바로 실패한다. 복도·협로·정밀 주차(약제실 dock)는 잘 된다. 예: 4인실 왼쪽 (38, 168) → (40, 162), 1인실 입구 (39.9, 101.3) → (65, 108).
- 로봇 재부팅 직후 `nav2_ready` true여도 처음 `/goto`가 "FollowPath 거부됨"으로 실패한 적이 있다(10-23). 잠시 뒤 다시 보내니 됐다.
- 손으로 로봇을 옮기면 위치가 갱신되지 않는다 → `POST /set_pose {"find": true}`.
- 로봇 notify(`PUT /notify`)가 EMR `/robot/arrived`에 연결돼 있어 PHARMACY 도착 시 EMR이 자동으로 "도착"이 된다(10-23 확인, A2 참고).
