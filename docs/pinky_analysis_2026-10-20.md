# Pinky 분석 — 웹(EMR)에서 배송 전달을 위한 현황 (2026-10-20)

- 목적: 실물 주행이 확인됐으니(EMR 장소 → Pinky 이동, 비품실 1곳 29초 도착), EMR 웹에서 배송을 Pinky에 **전달**하려면 무엇이 있고 무엇이 없는지 정리한다.
- 방법: 켜져 있는 Pinky를 PC에서 **읽기만** 했다(ROS 2 노드·토픽·액션·서비스·파라미터 조회, 웹서버 상태 조회). 명령은 보내지 않았다.
- 범위: 로봇(Pinky) 갈래 + 웹과 맞출 계약. OMX는 다루지 않는다.

## 1. 결론

1. **주행은 준비됐다.** 로봇 Nav2가 EMR과 같은 맵(`/home/pinky/maps/map_rev2.yaml`)으로 돌고, EMR 장소 좌표로 보낸 목표에 도착했다.
2. **빠진 것은 세 가지다**: ① 웹에서 "이 배송을 출발시켜라"를 로봇에 넘기는 프로그램 ② 결과(도착·실패)를 EMR에 돌려주는 경로 ③ 수령 확인용 카메라(마커 인식).
3. **네트워크가 막는다.** 이 PC가 Pinky 와이파이(AP, 192.168.4.x)에 붙어 있어 병원 LAN(192.168.129.x)에서 떨어졌다 → 지금은 다른 PC가 EMR 웹에 들어올 수 없다.
4. 권장: 먼저 **이 PC에서 도는 "배송 실행기"**(EMR에서 배송을 받아 Pinky로 보내고 결과를 올림)로 1대 배송을 끝까지 연결한다. 로봇 안 프로그램은 나중(여러 대·운영)에.

## 3. 웹 → Pinky 전달 방법 (선택지)

| | A. EMR 서버가 로봇을 직접 호출 | **B. PC의 배송 실행기 (권장)** | C. 로봇 안 프로그램 |
|---|---|---|---|
| 흐름 | 간호사 "출발" → api가 Pinky `:8080/api/goal` 호출 | 실행기가 EMR에서 배송을 가져옴(claim) → Pinky로 목표 → 진행·결과를 EMR에 보고 | 로봇이 EMR을 조회(claim) → 직접 Nav2 → 보고 |
| EMR 결정(2026-10-19 "로봇 쪽 프로그램이 EMR을 조회")과 | 어긋남 | 맞음 (로봇 쪽 = 관제 PC) | 맞음 |
| 결과 알기 | 못 함(웹서버가 결과를 안 줌) | ROS 액션으로 정확히(도메인 0) 또는 HTTP+위치 | 정확히 |
| 로봇 수정 | 없음 | 없음 | 로봇에 배포·키 보관 필요 |
| 여러 대 | 어려움 | 실행기가 로봇별로 | 자연스러움 |
| 지금 있는 것 재사용 | — | `test_waypoint.py`(이동·판정), `robot_monitor`(상태) | — |

B를 권하는 이유: 로봇을 건드리지 않고, 오늘 확인한 경로(EMR 좌표 → Nav2)를 그대로 쓰며, 로봇 키를 로봇에 옮길 필요가 없다. 결과는 웹서버 대신 ROS 액션(`navigate_to_pose`)으로 받는 편이 정확하다.

## 5. 필요한 작업 (갈래별)

**웹(EMR) — 로드맵 2단계, 계약 확정 후**
1. 배송 상태 `reserved → dispatched → arrived → received` / `failed(사유)`, 간호사 화면에 단계 표시, 수령 완료처럼 단계 알림.
2. 로봇 API: `POST /robot/deliveries/claim`(예약 시각 지난 것부터 1건), `POST /robot/deliveries/{id}/progress`.
3. 로봇별 복귀 장소(예: 간호사스테이션).

**로봇(Pinky·관제) — B안**
1. 배송 실행기(`robot/src/fms/`): claim 폴링 → 목적지 좌표로 `navigate_to_pose`(ROS 액션, 도메인 0) → `progress`(dispatched·arrived·failed) → 수령 대기 → 복귀.
2. 로봇 키는 이 PC 설정 파일(권한 600)에 보관.
3. 네트워크 정리(4장 #1).
4. 수령 확인: 카메라 노드 + 마커 인식, 또는 임시로 웹 버튼.

## 7. 정해야 할 것 (사용자)

1. 전달 방식 B(PC 실행기)로 갈지.
2. 수령 확인을 당분간 어떻게 할지 — 카메라를 붙일지, 웹에서 간호사가 누를지.
3. 네트워크: Pinky를 병원 공유기에 붙일지, PC에 LAN을 하나 더 쓸지.
4. 출발 시점: 예약 시각이 되면 자동 출발인지, 간호사·관리자가 "출발"을 누르는지.
5. 못 가는 장소(비품실 등)를 어떻게 막을지 — 장소에 "주행 금지" 표시 vs Nav2 금지 구역.
