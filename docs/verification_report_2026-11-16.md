| SR | 내용 | 구현 | 판정 |
|---|---|---|---|
| SR-01 / SRD-01 | 비품 관리, 재고 | 비품 등록·검색·삭제, 재고, 유효기간 자동, 재고 부족 알림 | ✅ 완료 |

| SR-05 [O] | 기록, 모니터링 | 배송 기록(DB, 단계별)과 서버 로그 | ⚠️ 통합 모니터링은 연동 후 작업 |
| SR-06 | 수령 확인 | "받았습니다" 버튼 (간호사, 병상 환자) | ✅ 완료 (마커에서 버튼으로 방식 변경) |
| SR-07 | 알림, 영상 중계 | 실시간 알림(SSE). 영상은 탑뷰 중계(UDP, AWS SRT) | ⚠️ 일부 (알림 완료, 영상은 일부) |
| SR-08 | 알림, 역할 권한 | JWT 로그인, 관리자·간호사 역할, 로봇·병상 단말 키 | ✅ 완료 (시험 중에만 `AUTH_DISABLED`, `ROBOT_KEY_DISABLED`로 끔) |

| SR-10 / SR-12 [O] | 비품 식별, 포즈 | OMX 탑 카메라 YOLO(파란·녹색 거즈) | ✅ 완료 |

| SRD-07 [O] | 오브젝트 스토리지 | 지도 이미지는 DB에 저장, 영상은 실시간 중계만 | ➖ 옵션, 불필요로 제외 |

삭제된 SR-03과 옵션 SRD-07은 충족률 계산에서 뺐습니다. `[O]`는 옵션 요구사항입니다.

### 확장 기능

배송 흐름과 독립적으로 동작하는 프로젝트 기능입니다. SR 번호가 없어서 위 충족률에는 따로 넣지 않았습니다.

| 기능 | 내용 | 실물 확인 |
|---|---|---|
| **병원 안내** (`guide_robot/`) | Pinky가 처음 가 보는 곳을 복도 따라 돌아다니며 RTAB-Map으로 지도를 만들고, 사람이 보이면 멈춰 한국어로 인사(LCD, LED, 소리). 사람이 아닌 장애물에는 길을 양보 | 6단계 중 5단계 완료 (테이프 선 진행 중) |
